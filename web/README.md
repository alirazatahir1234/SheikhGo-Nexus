# SheikhGo-Nexus-ERP — Web

Angular frontend for **SheikhGo-Nexus-ERP** (feed mills & poultry ERP). API base: `http://localhost:5080/api`.

## Prerequisites

- Node.js 20+ (LTS recommended)
- Backend API running on port **5080**

## Install & run

```bash
cd web
npm install
npm start
```

App: [http://localhost:4200](http://localhost:4200)

Demo login: `admin@softaxe.local` / `Admin@123`
